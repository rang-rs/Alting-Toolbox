# Alting Toolbox

Dims the screen until your boosts, health, prayer, poison protection, cannon or selected drops need attention. Each alert can be toggled and given a colour, with flashing or solid overlays.

Enter drop item IDs separated by commas. Drop alerts and optional sounds repeat until the matching items leave the ground or your configured range.

Ctrl+Alt+D pauses the overlay and sounds. Hold Alt to move the text overlay. The cannonball prefix is empty by default.
